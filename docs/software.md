# Software

## Main Application

The calculator application is written in Python.

## Technologies

- Python
- Tkinter
- SymPy
- OpenAI API
- threading
- subprocess
- Base64 image encoding
- Raspberry Pi camera tools

## Application Modes

### CALC
Offline scientific calculator.

### AI
Engineering assistant that provides short step-by-step solutions.

### CAMERA
Captures an image and sends it to an AI vision model for analysis.

### ENGINEERING
Offline engineering formula and reference library.

## Development Environment

- Raspberry Pi OS 64-bit
- Python virtual environment
- Git
- GitHub
